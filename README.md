
# Python for DevOps

A hands-on Python automation learning repository
focused on Linux administration, AWS automation,
server monitoring and DevOps practices.

## Projects

### 1. Server Monitoring
- Monitor CPU usage
- Monitor RAM usage
- Monitor disk usage
- Identify system information

### 2. Automated Backup
- Automate directory backups
- Copy files using shutil
- Generate timestamped backups

### 3. Linux Command Automation
- Execute Linux commands using subprocess
- Capture command output
- Check server uptime
- Monitor disk and memory usage
- Handle command execution errors

## Technologies
- Python 3
- Ubuntu Linux
- AWS EC2
- Git
- GitHub

## Learning Objective
Build practical Python automation skills
for real-world DevOps engineering tasks.
